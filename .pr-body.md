## Summary

This PR introduces a comprehensive structured learning session system alongside improvements to the recommendation engine, topic progress tracking, and platform reliability.

### Structured Learning Sessions
- **Session engine** (`lib/session/sessionEngine.ts`): State machine driving students through EXPLANATION, PRACTICE, TEST, HOMEWORK, COMPLETE phases
- **Phase content resolution** (`lib/session/getPhaseContent.ts`): Fetches real TopicNotes, Questions, GeneratedTests, and HomeworkAssignments per phase
- **Phase transition validation** (`lib/session/transitionSessionPhase.ts`): Enforces strict linear transitions with phaseStartedAt timestamps
- **Session APIs**: POST /api/session/start, next, complete; GET /api/session/resume, /api/session/[sessionId]
- **Session page**: Full interactive UI rendering notes, practice MCQs, tests, and homework per phase
- **Resume card** on dashboard: Auto-detects active sessions and shows "Resume Your Lesson"

### Homework System
- **Homework generation** (`lib/session/homework.ts`): 5-10 questions from Question bank or GeneratedQuestion fallback
- **Submission API** (POST /api/homework/submit): Auto-grading MCQs with answer normalization
- **Overdue detection** (GET /api/student/homework): Automatically transitions PENDING to OVERDUE when past due
- Added OVERDUE to HomeworkStatus enum

### Topic Progress
- **Centralized service** (`lib/learning/updateTopicProgress.ts`): Single source of truth for all mastery updates with activity-aware weights (HOMEWORK: 0.2, PRACTICE: 0.1, TEST: 0.3, STUDY: touch-only)
- Migrated all 5 callers (test submit, homework submit, session complete, progress API, lesson view)

### Recommendation Engine
- Topic-based recommendation with topicRanker.ts
- Tutor Recommendation Card on dashboard
- Admin observability dashboard with studentId/topicId/date filters and expandable signal detail rows
- Recommendation trace persistence with feature flag

### Bug Fixes
- Fixed wrongCount undefined reference in homework submission logger
- Fixed all TypeScript errors (Prisma v6 SessionPhase import, unknown type inference)
- Fixed all ESLint warnings (unused variables)

### LearningSession Bridge
- StructuredSession creates/updates/completes a paired LearningSession so existing recommendation signals (resume, recency, engagement) continue working
