## Summary

This PR merges the `develop` integration branch into `master`, delivering new admin tooling, student learning-map routes, public pages, and platform hardening completed across multiple feature branches.

### Admin Pages

- **Content Moderation Dashboard** (`app/admin/moderation/`): SSR-prefetched moderation queue with approve/reject/flag actions; auto-refreshes every 30s
- **Analytics dashboard** (`app/admin/`): Platform-wide usage and engagement metrics

### Student Learning Map

- **Learning Map home** (`app/(student)/student/learning-map/page.tsx`): S2.1 learning map entry point with subject/topic grid
- **Topic lesson view** (`app/(student)/student/learning-map/topic/[topicId]/page.tsx`): S2.2 lesson experience page
- **Topic practice flow** (`app/(student)/student/learning-map/topic/[topicId]/practice/page.tsx`): S2.3 practice MCQ flow

### Public Pages

- **Register/signup** (`app/(public)/auth/signup/`): Account creation flow
- **Explore** (`app/(public)/explore/`): Public subject/topic explorer
- **Data security** (`app/(public)/data-security/`): DPDP compliance page

### Dev Tooling & Security

- **dev-login** (`app/(public)/dev-login/route.ts`): Hardened — now requires `ENABLE_DEV_LOGIN=1` flag and fails fast if `NEXTAUTH_SECRET` is unset; hard-blocked in production

### Infrastructure

- `.dockerignore`: Added `.env`, `docs`, `tests`, `__tests__`, `.github` to keep build context clean and prevent accidental secret inclusion
- CI workflow updates (`.github/workflows/`)
- Updated `CLAUDE.md`, `README*.md`, `DEPLOYMENT.md`, `WORKER_README.md`

### Bug Fixes & Code Quality

- Fixed TypeScript errors and ESLint warnings across modified files
- Silent SSR catch blocks replaced with structured logger calls
- Params type corrected from `Promise<{...}>` to plain object in App Router pages
