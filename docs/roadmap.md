# Spinzy Academy — Roadmap

## Phase 1 — Foundation (CURRENT)

Goal: First real student can complete full learning loop end to end.

Milestones:

- [x] Auth (Google OAuth)
- [x] Onboarding (grade, board, subjects, language)
- [x] Taxonomy seeded (CBSE + ICSE, Grades 1-12)
- [x] Content pipeline (Syllabus -> Notes -> Questions)
- [x] Admin panel (11 sections)
- [x] Email (Resend, welcome, parent OTP, digest)
- [ ] Diagnostic flow (questions -> knowledge map)
- [ ] AI tutor session (Vidya, structured phases)
- [ ] LearningPlan generation
- [ ] Content generated for CBSE Gr10 core subjects

## Phase 2 — Quality & Retention

Goal: Students return daily. Parents see value.

- [ ] Spaced repetition (SM-18 revision queue)
- [ ] Streak system (shields, XP, levels)
- [ ] Parent dashboard (read-only, weekly digest)
- [ ] IRT question calibration (post 100 answers)
- [ ] NCERT scraper grounding (real chapter names)
- [ ] Content for Grades 9, 8, 6 (CBSE core)
- [ ] Push notifications
- [ ] Freemium gate (session cap)

## Phase 3 — Scale & Monetisation

Goal: First 1000 paying students.

- [ ] Razorpay / UPI payment integration
- [ ] Subscription plans (monthly/annual)
- [ ] ICSE content generation
- [ ] Grades 1-5 content
- [ ] Regional language support (Hindi medium)
- [ ] Staging -> production promotion pipeline
- [ ] CDN + image optimization
- [ ] Multi-VPS deployment
- [ ] SLA monitoring + alerting

## Non-goals (deliberately excluded)

- Video content
- Live tutoring / human handoff
- Social features (leaderboards, chat)
- Gamification beyond XP/streaks
